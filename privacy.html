Privacy Policy

Last updated November 3, 2026

Tipton Home is a personal home-automation app used only by one household. This policy explains how it handles data, including data from Google accounts.

What it accesses

With the owner's permission, the app uses the Google Smart Device Management API to read the status of the household's own Nest devices (such as thermostat temperatures and settings, and camera and doorbell events) and to control them, for example to change a thermostat setting.

How the data is used

The data is used only to show and control the household's own devices in the app and to run the household's own automations. It isn't used for advertising, profiling or any other purpose.

Where it's kept

All data, including the Google sign-in token, is stored on the household's own server at home. It isn't sent to or stored with any third party, other than the requests the app makes to Google's own services to read and control the devices.

Sharing

Data is never sold, rented or shared with anyone.

Removing access

Access can be revoked at any time from the Google account's security settings (Third-party apps with account access). Revoking it stops the app from reaching the devices, and the stored token is then useless.

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
